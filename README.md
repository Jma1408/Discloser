# DisCloser

Site caché « terrier de lapin » de l'ARG **DisCloser** (design Windows XP, 5 onglets, terminal).

## Déposer le code du projet

Copier ici **tout le contenu du dossier VSCode, en gardant exactement la même hiérarchie** (HTML, CSS, JS, assets…), directement à la racine de ce dépôt.

- **Depuis VSCode / terminal :**
  ```bash
  git clone https://github.com/jma1408/discloser.git
  cd discloser
  git checkout claude/laughing-darwin-ae2e4f
  # copier les fichiers du projet ici, puis :
  git add .
  git commit -m "Import du projet existant"
  git push
  ```
- **Depuis le site GitHub :** onglet *Code* → choisir la branche `claude/laughing-darwin-ae2e4f` → *Add file* → *Upload files* → glisser-déposer les **dossiers** (la hiérarchie est conservée).

Le brief complet du projet (scénario, règles, tâches) est dans [`CLAUDE.md`](CLAUDE.md).
